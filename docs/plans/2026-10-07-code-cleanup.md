# 全项目代码清理

用户要求：检索全项目，删除无用代码和功能恢复后失效的报错阻断，去除掩盖错误的防御式兜底，简化繁琐实现。保留前一轮微信语音主动调用链删除修改。

## 范围与方法

- 扫描受版本管理的 Python、JavaScript、TypeScript、Vue、Electron 与官网源码、工具和测试；第三方 vendor、依赖、生成产物、用户数据不作为自有源码改写。
- 首轮词引用及 Python AST 索引覆盖 891 个文件、301369 行，产生 44 个单引用定义和 73 个未用导入候选。候选必须人工复核；框架覆盖方法、路由注册和导入副作用不能按静态计数删除。
- 各项沿现有调用链小步修改，运行相关测试后再做集成验证。无需新依赖或架构迁移。

## 实施检查表

- [x] 后端非 AI：核对图片发送恢复链、历史能力阻断和无调用辅助函数。
- [x] 前端：删除账号 HTTP 失败后的桌面绕行、旧接口兼容和复制假成功；保留真实错误及异步隔离。
- [x] AI/MCP：清理无用旧设置接口和辅助函数，停止将损坏缓存当作缺失。
- [x] 桌面与工具：删除重复账号磁盘操作链，简化失败被默认值或截图降级掩盖的路径，核对未用代码。
- [x] 集成验证：前端、桌面、后端相关测试和生产前端构建，复核残留引用与变更。

## 已落实的清理

- 图片发送：内部 bridge 必须接收账号、会话，删除缺少确认条件仍执行发送、随后必报未确认的旧分支。HTTP 生产调用一直提供这两个参数。已恢复的 Qt 图片发送路径没有遗留的全局禁用开关；不支持的非 Qt 客户端和确实未获确认的发送仍明确报错。
- 后端非 AI：删除 36 个无调用函数、1 个无人消费结果的 ZIP 代理类、49 个未用导入。ZIP 校验继续基于归档实际写入的所有成员计算；不保留另一套未消费的哈希计算。
- 账号管理：删除前端 HTTP 失败后切换桌面磁盘操作的分支及对应 IPC、预加载接口和辅助函数。账号读取和删除统一经过现有 HTTP 入口的校验与错误展示。
- 错误可见性：复制只使用实际剪贴板写入结果；空发送回执不再清空草稿；空 AI 建议、异常搜索响应明确失败。设置更新失败后刷新实际状态，再保留原始错误，避免刷新把失败提示清空。
- 桌面设置：缺省配置才使用默认值；损坏 JSON、无效端口、目录读写和保存失败明确抛错。原子写成功后才替换内存设置与输出目录环境变量；数据迁移和回滚流程保留。
- 桌面截图与启动：去除截图失败后悄悄换截图方式的支路；启动错误直接显示原始异常，不再次读取已经失败的设置。日志写入失败打印到标准错误，不能阻断错误窗口及退出清理。
- AI/MCP：删除无调用辅助函数、没有实际设置行为的旧额度 API、仅测试使用的生产构造参数；批次容量只保留一份实现。模型配置异常、损坏的转写及年报缓存、非法 MCP 参数不再被默认值或空结果掩盖。
- 记录导出：修复来源字段生产者与调用方契约不一致导致的真实 500 错误；统一为 `dataSource`。归档入口严格校验来源，不把未知或缺失来源伪装成 decrypted。
- 官网与工具：删除没有 DOM 或调用入口的 DataRiver/buildStack 及孤立样式，清掉分析脚本中无调用函数和未用导入；依赖的生成代码不改写。
- 后续约束：根目录 `AGENTS.md` 固化入口校验、禁止伪成功/隐式降级、功能恢复后清理旧阻断和分层验证的规则。

- 前端全套：98 项 Node 测试、778 项 Vitest 测试通过；Nuxt 静态构建成功生成 32 条路由。性能测试补齐状态接口夹具后单文件 2 项再次通过。
- 桌面全套：111 项 Node 测试通过，包含配置损坏、保存失败不改变内存、截图失败及启动错误报告路径。
- 后端：按完整收集范围分批执行。首批 1203 passed / 12 failed；后续 2623 passed / 25 failed / 2 skipped，另 235 个子测试通过。这里两批有账号测试重叠，不能相加作为唯一测试数量。
- 失败项已逐项定位并修正：21 个涉及失败的文件统一最终复验 **165 passed**。本轮删除构造参数和容量包装后同步修正测试调用；原本依赖缺失模型配置时静默默认容量的夹具改为提供真实模型配置快照。历史 realtime/Hook 断言、无有效快照的账号夹具、未关闭的 SQLite 连接及漏传 checkpoint 参数均按现有实现修正。
- 离线进程测试：真实临时数据库解密、读取、导出及模拟 2027/2030 时间共 3 项通过。原数据库和已发布快照逐字节不变；刷新仅新增预期的 `anti_revoke.db`，归档代号与快照代号一致。
- 两项跳过原因已单独复核：当前 Windows 测试进程没有创建文件/目录符号链接的权限（WinError 1314），涉及源库符号链接保护及模型目录符号链接保护；没有关闭这些校验或改成假通过。
- 测试复用本机缓存中的 pytest 和现有桌面 FFmpeg。隔离进程所需的临时依赖路径文件已在验证后删除，没有引入项目运行依赖。
- 修改过的 Python 文件 AST 解析、桌面及官网脚本语法检查、`git diff --check` 均通过。详细运行日志在忽略目录 `tmp/cleanup-*-tests.log`、`tmp/cleanup-*-pytest.log`、`tmp/cleanup-frontend-build.log` 和 `tmp/cleanup-skip-reasons.log`。
- 独立复核：非 AI 后端、桌面、工具与官网变更的调用和删除边界已复核；发现的启动错误报告回归已修复并加入测试。

## 保留边界

权限、隐私、账号来源校验、文件和数据库一致性、取消、迟到响应隔离、未知发送结果及防止重复发送都属于现有业务正确性要求。真实未支持的能力应继续明确报错，不能删除报错后伪装支持。

不操作真实微信发送，不读写用户聊天数据库，不删除旧安装包或历史验收数据。自动化测试与构建不等同于真实模型、微信客户端或安装包验收。
